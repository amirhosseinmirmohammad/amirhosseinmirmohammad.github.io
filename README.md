# 💳 کارت ویزیت دیجیتال NFC — امیرحسین میرمحمد

صفحه شخصی که با نزدیک کردن تگ NFC به گوشی، روی هر گوشی باز میشه.

## 📁 فایل‌ها

- `index.html` — کل صفحه (اطلاعات داخلش در بخش `CONFIG` بالای اسکریپت هست)

## 🌐 مرحله ۱: آپلود روی GitHub Pages (رایگان)

1. وارد [github.com](https://github.com) شو (اگه اکانت نداری بساز — همون یوزرنیم گیت‌هاب: `amirhosseinmirmohammad`)
2. دکمه **+** بالا سمت راست → **New repository**
3. اسم ریپازیتوری رو بذار: `amirhosseinmirmohammad.github.io`
   > با این اسم، آدرس صفحه‌ات میشه: `https://amirhosseinmirmohammad.github.io` ✨
4. بذار Public باشه → **Create repository**
5. توی صفحه ریپو روی **uploading an existing file** کلیک کن (یا Add file → Upload files)
6. فایل `index.html` رو بکش و رها کن
7. دکمه **Commit changes** رو بزن
8. برو به: `Settings` → `Pages` (از منوی سمت چپ)
9. توی بخش Source گزینه **Deploy from a branch** رو انتخاب کن، Branch رو بذار `main` و پوشه `/ (root)` → **Save**
10. بعد از ۱ تا ۲ دقیقه صفحه‌ات روی این آدرس بال میاد:
    **https://amirhosseinmirmohammad.github.io**

> 💡 اگه خواستی آدرس کوتاه‌تر باشه، می‌تونی یه دامنه اختصاصی مثل `me.amirhmirm.ir` هم وصل کنی (چون سایت خودت رو داری).

## 📲 مرحله ۲: نوشتن روی تگ NFC با آیفون (iPhone 16 Pro)

### خرید تگ
یه **برچسب (استیکر) NFC از نوع NTAG213 یا NTAG215** بخر — تو اینترنت (دیجی‌کالا/ترب و...) یا علافک فروشی‌ها پیدا میشه، قیمتش خیلی کمه.
> NTAG213 حدود ۱۴۴ بایت فضا داره که برای لینک گیت‌هاب پیجز کاملاً کافیه.

### نوشتن با اپ NFC Tools
1. از App Store اپ **NFC Tools** رو نصب کن (رایگان)
2. گوشی رو آنلاک کن، اپ رو باز کن
3. تب **Write** → **Add a record** → **URL/Website**
4. آدرس صفحه‌ات رو وارد کن: `https://amirhosseinmirmohammad.github.io`
5. بزن روی **Write** → تگ رو **به لبه بالای گوشی** (نزدیک دوربین سلفی) بچسبون
6. صبر کن پیام «Write complete» بیاد ✅

> 📱 نکته آیفون: آنتن NFC آیفون بالای گوشیه، پس تگ رو همون‌جا نگه دار. موقع نوشتن اینترنت لازم نیست ولی صفحه‌ی آیفون باید روشن و آنلاک باشه.

### (اختیاری) قفل کردن تگ
توی NFC Tools بخش **Other** → **Lock tag** — بعد از قفل هیچ‌کس نمی‌تونه روش بنویسه.
> ⚠️ بعد از قفل برگشت‌ناپذیره، اول مطمئن شو لینک درسته و تست کردی.
